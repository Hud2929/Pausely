# Pausely - Promotional text variants

Promotional text (170 characters at most) can be changed in App Store Connect at any time without a
new build or review, so it can follow the season. It is not indexed for search: write it for people.

The one in use is `promotionalText` in `metadata/version/<version>/<locale>.json`, which
`StoreListingTests` holds to its limit. The variants below are English only; each says only what the
app does today, and each needs its five translations before it is used.

## In use
```
Before every renewal, Pausely asks: keep it or cancel it? Your Savings Receipt shows what you saved, and Pausely tells you to cancel it if it isn't worth it.
```

## New year
```
A clearer new year: see every subscription, what it costs a year and which renewals are coming. Before each one, Pausely asks: keep it or cancel it?
```

## Free-trial season (Black Friday, holidays, back to school)
```
Holiday free trials renew on their own. Add them to Pausely and get a reminder before the first charge, so you only pay for what you choose to keep.
```

## Streaming
```
Paying for several streaming services? Pause Plan keeps one on and tells you when to cancel the rest and when to start each one again.
```
