# Pausely - Promotional Text Variants

Promotional text (170 chars max) can be changed in App Store Connect at any time **without a new build or review**, so rotate it with the season. It is not indexed for search, so write it for people, not keywords.

Rules: only claim what the app does today. No user counts, savings averages, testimonials, "AI", "Smart Pause" or Gmail scanning (see `APP_STORE_LISTING.md`, "What this listing must never claim"). Translate through `scripts/store_copy.py` and have a native speaker review before use.

## Default (use at launch)  (151/170)
```
Never be surprised by a renewal again. Track every subscription, get alerts before free trials end and prices rise, and see what each one really costs.
```

## New year  (135/170)
```
A clearer new year: see every subscription, what it costs per year and which renewals are coming up. Get alerts before free trials end.
```

## Free-trial season (Black Friday, holidays, back to school)  (138/170)
```
Holiday free trials auto-renew. Add them to Pausely and get an alert before the first charge, so you only pay for what you choose to keep.
```

## Price increases  (138/170)
```
Prices rise quietly. Pausely keeps your price history and alerts you when a subscription costs more, so you can decide whether to keep it.
```

## Cancel easier  (124/170)
```
Ready to cancel? Pausely links straight to the cancellation page for 900+ services and shows how hard each one is to cancel.
```
