# Faces for the App Store pictures

`scripts/store_frames.swift` sets the captions in these. All are under the SIL Open Font License 1.1,
which allows them in pictures and allows the files to be passed on with this notice; the app itself
does not ship them (its type is the system's).

| File | Family | Used for | From |
|---|---|---|---|
| `Newsreader-Display-SemiBold.ttf`, `Newsreader-Display-SemiBoldItalic.ttf` | Newsreader (Production Type) | headlines in English, French, Spanish and German | fonts.google.com/specimen/Newsreader |
| `IBMPlexMono-Medium.ttf` | IBM Plex Mono (IBM) | the small line above a headline | fonts.google.com/specimen/IBM+Plex+Mono |
| `NotoSerifJP-Bold.ttf`, `NotoSansJP-Medium.ttf` | Noto Serif JP, Noto Sans JP (Google) | Japanese | fonts.google.com/noto |
| `NotoNaskhArabic-Bold.ttf`, `IBMPlexSansArabic-Medium.ttf` | Noto Naskh Arabic (Google), IBM Plex Sans Arabic (IBM) | Arabic | fonts.google.com/noto |

The licence text: https://openfontlicense.org/open-font-license-official-text/

The system's own serif (New York) is what the app draws its questions in. It is not used here:
Apple licenses it for interfaces on its platforms, not for marketing pictures.
